# Beecrowd 1016 - Distância

**Adaptado por:** Neilor Tonin, URI[cite: 2]  
**Timelimit:** 1[cite: 2]  

Dois carros (X e Y) partem em uma mesma direção[cite: 2]. O carro X sai com velocidade constante de 60 Km/h e o carro Y sai com velocidade constante de 90 Km/h[cite: 2].

Em uma hora (60 minutos) o carro Y consegue se distanciar 30 quilômetros do carro X, ou seja, consegue se afastar um quilômetro a cada 2 minutos[cite: 2].

Leia a distância (em Km) e calcule quanto tempo leva (em minutos) para o carro Y tomar essa distância do outro carro[cite: 2].

## Entrada

O arquivo de entrada contém um número inteiro[cite: 2].

## Saída

Imprima o tempo necessário seguido da mensagem "minutos"[cite: 2].

| Exemplo de Entrada | Exemplo de Saída |
| :--- | :--- |
| 30 | 60 minutos |
| 110 | 220 minutos |
| 7 | 14 minutos |
